# ذكرني | Zekrni

تطبيق إسلامي بسيط يجمع الأدوات اليومية التي تساعد المسلم على الذكر وقراءة القرآن ومعرفة مواقيت الصلاة.

## ✨ المميزات

- 📿 سبحة إلكترونية مع عدّاد وإمكانية إعادة التصفير.
- 📖 المصحف الشريف مع إمكانية البحث عن السور وعرض الآيات.
- 🕌 مواقيت الصلاة لمدينة دمياط.
- 🎨 واجهة عربية تدعم اتجاه الكتابة من اليمين إلى اليسار.
- 📱 تحويل المشروع إلى تطبيق Android باستخدام Capacitor.

## 🛠️ التقنيات المستخدمة

- HTML
- CSS
- JavaScript
- Capacitor
- Android Studio

## 🚀 تشغيل المشروع

1. نزّل المشروع من GitHub.
2. ثبّت Node.js.
3. افتح Terminal داخل مجلد المشروع.
4. نفّذ `npm install`.
5. لمزامنة ملفات الويب مع Android، نفّذ `npx cap sync android`.
6. افتح مشروع Android باستخدام Android Studio لبنائه وتشغيله.
